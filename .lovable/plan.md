

# 💕 "Be My Valentine" Interactive Website

## Page 1: The Valentine Question
A beautiful, playful landing page with:
- **Animated Background**: Floating hearts, subtle sparkles, and a soft gradient (pink to red)
- **Main Question**: Large, bouncy "Will You Be My Valentine? 💕" heading with a cute font
- **Two Buttons**: 
  - **"Yes" button** - Pink/red gradient, starts normal size
  - **"No" button** - Smaller, gray or lighter color

### Interactive Magic ✨
- **No Button Behavior**:
  - On hover (desktop) or click (mobile), the button "escapes" to a random position on screen
  - Gets smaller and harder to catch each time
  - Funny messages appear like "Nope!", "Can't catch me!", "Try again!"
  
- **Yes Button Growth**:
  - Each time "No" escapes, "Yes" grows slightly bigger
  - Adds visual emphasis with pulsing/glowing effects
  - After several attempts, transforms into two large buttons: "Yes 💖" and "Absolutely Yes! 💕"

### Visual Polish
- Bouncy spring animations
- Heart particles following the cursor
- Smooth, playful transitions
- Responsive design for both desktop and mobile
